## Od klocka Scratcha do if w C

Klocek `if < > then … else` ze Scratcha wygląda w C bardzo podobnie. Program porównuje dwie liczby:

```c title="porownaj.c"
#include <stdio.h>

int main(void)
{
    // int (od integer): dwie zmienne na liczby całkowite
    int x;
    int y;

    printf("Podaj x: ");
    // %d: wczytaj liczbę całkowitą, &x: adres, pod który ją zapisać
    scanf("%d", &x);
    printf("Podaj y: ");
    scanf("%d", &y);

    // Warunki sprawdzamy po kolei. Wykona się tylko jedna gałąź.
    if (x < y)
    {
        printf("x jest mniejsze od y\n");
    }
    else if (x > y)
    {
        printf("x jest większe od y\n");
    }
    else
    {
        // ani mniejsze, ani większe, czyli równe
        printf("x jest równe y\n");
    }
}
```

Warunek stoi w nawiasach okrągłych, a to, co ma się wykonać, w klamrowych. Komputer sprawdza warunki po kolei i wykonuje **tylko pierwszą** pasującą gałąź. Ostatnie `else` nie potrzebuje warunku: jeśli x nie jest ani mniejsze, ani większe od y, to musi być równe.

<Ramka tytul="Przypomnienie: int x i &x">
- **`int x;`** tworzy zmienną o nazwie `x` na liczbę całkowitą. W C każda zmienna musi mieć typ, dlatego `int` stoi przed nazwą. Nie ma to nic wspólnego ze stałą. Stałą zrobiłoby z `x` dopiero słowo `const` i wartość nadana od razu: `const int X = 5;`. Różnice między zmienną a stałą opisuje moduł „Typy danych”.
- **`&x`** to adres zmiennej `x`, czyli numer jej szufladki w pamięci. `scanf` musi wiedzieć, **gdzie** zapisać wczytaną liczbę, więc dostaje adres, a nie zawartość zmiennej. W `printf` znaku `&` nie piszemy, bo tam chodzi o wartość. Więcej w module „printf i scanf”.
</Ramka>

<Wskazowka tytul="Dlaczego nie trzy osobne if?">
Można napisać trzy niezależne `if`: `x < y`, `x > y` i `x == y`. Program działałby poprawnie, ale zawsze sprawdzałby wszystkie trzy warunki, nawet gdy pierwszy już się spełnił. `else if` oszczędza pracy i lepiej pokazuje, że gałęzie się wykluczają. To różnica w **projekcie** programu, a nie w jego poprawności.
</Wskazowka>

## Porównania

| operator | znaczenie | przykład |
|---|---|---|
| `<` | mniejsze | `x < 10` |
| `>` | większe | `x > 0` |
| `<=` | mniejsze lub równe | `wiek <= 18` |
| `>=` | większe lub równe | `punkty >= 50` |
| `==` | równe | `x == y` |
| `!=` | różne | `odpowiedz != 'n'` |

<Uwaga tytul="Jeden znak = to nie porównanie">
`if (x = 5)` nie sprawdza, czy x równa się 5. Wpisuje do x piątkę, a warunek jest wtedy zawsze spełniony. Porównanie to **dwa** znaki: `if (x == 5)`. GCC z opcją `-Wall` ostrzeże przed tym błędem.
</Uwaga>

## I, lub, nie

Warunki można łączyć jak klocki `and`, `or` i `not` w Scratchu:

| C | znaczenie | przykład |
|---|---|---|
| `&&` | i (oba warunki) | `wiek >= 18 && wiek <= 65` |
| `\|\|` | lub (co najmniej jeden) | `odpowiedz == 't' \|\| odpowiedz == 'T'` |
| `!` | nie (odwraca) | `!(x == 0)` |

Przykład: program pyta o zgodę i przyjmuje małą albo wielką literę.

```c title="zgoda.c"
#include <stdio.h>

int main(void)
{
    // char: zmienna na jeden znak
    char odpowiedz;

    // Pytanie to napis, więc stoi w cudzysłowie
    printf("Zgadzasz się? (t/n) ");
    // Spacja przed %c pomija Enter i spacje, które zostały w kolejce
    scanf(" %c", &odpowiedz);

    // Pojedyncze znaki porównujemy w apostrofach: 't', a nie "t"
    if (odpowiedz == 't' || odpowiedz == 'T')
    {
        printf("Zgoda.\n");
    }
    else if (odpowiedz == 'n' || odpowiedz == 'N')
    {
        printf("Brak zgody.\n");
    }
    else
    {
        printf("Nie rozumiem.\n");
    }
}
```

Dlaczego pytanie stoi w cudzysłowie `" "`, a litery w apostrofach `' '`? To reguła języka C. Pytanie to **napis**, czyli wiele znaków, więc zapisujemy je w cudzysłowie. Odpowiedź to **jeden znak** typu `char`, a pojedynczy znak zapisuje się w apostrofach. Dla C `'t'` to po prostu liczba 116, czyli kod litery t, więc porównanie `odpowiedz == 't'` porównuje dwie liczby.

Gdy pomylisz apostrofy z cudzysłowem i napiszesz `odpowiedz == "t"`, warunek nigdy nie będzie spełniony, a GCC ostrzeże: `comparison between pointer and integer`. Szczegóły są w module „Typy danych”, w części „Apostrof czy cudzysłów?”.

<Dociekliwi tytul="switch: wiele przypadków naraz">
Gdy jedną zmienną porównujesz z wieloma konkretnymi wartościami, wygodniejsze bywa `switch`:

```c
switch (odpowiedz)
{
    case 't':
    case 'T':
        printf("Zgoda.\n");
        break;    // koniec tego przypadku
    case 'n':
    case 'N':
        printf("Brak zgody.\n");
        break;
    default:      // wszystko inne
        printf("Nie rozumiem.\n");
}
```

`break` kończy dany przypadek. Bez niego program „przeleci” do następnego `case`. To częsty błąd, więc na początku zostań przy `if`.
</Dociekliwi>
