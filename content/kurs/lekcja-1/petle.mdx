## Trzy razy miau

Najprostszy sposób to skopiować linijkę trzy razy:

```c
printf("miau\n");
printf("miau\n");
printf("miau\n");
```

Działa, ale to zły projekt. Gdyby kot miał miauczeć sto razy, trzeba by wpisać sto linijek. W Scratchu użylibyśmy klocka `repeat (3)`. W C mamy kilka rodzajów pętli.

## while: dopóki warunek jest spełniony

```c
int licznik = 0;       // ile razy już miauczał kot, na start 0
while (licznik < 3)    // dopóki licznik jest mniejszy od 3
{
    printf("miau\n");
    licznik++;         // licznik = licznik + 1
}
```

Pętla `while` sprawdza warunek **przed** każdym obrotem. Jeden obrót pętli to **iteracja**. Prześledźmy ją krok po kroku:

| licznik | `licznik < 3`? | co się dzieje |
|---|---|---|
| 0 | tak | miau, licznik = 1 |
| 1 | tak | miau, licznik = 2 |
| 2 | tak | miau, licznik = 3 |
| 3 | nie | koniec pętli |

Programiści liczą od zera, więc trzy obroty to wartości 0, 1 i 2. Warunek `licznik < 3` czytaj: „dopóki licznik jest mniejszy od 3”.

## for: wszystko w jednej linijce

To samo da się zapisać krócej:

```c
// for (początek; warunek; krok po każdym obrocie)
for (int i = 0; i < 3; i++)
{
    printf("miau\n");
}
```

W nawiasie są trzy części oddzielone średnikami:

| część | co robi | kiedy działa |
|---|---|---|
| `int i = 0` | **początek**: tworzy licznik i wpisuje 0 | raz, przed pierwszym obrotem |
| `i < 3` | **warunek**: czy robić kolejny obrót | przed każdym obrotem |
| `i++` | **krok**: zwiększa licznik o 1 | po każdym obrocie |

Najtrudniejsze w pętli `for` jest to, że trzy części stoją obok siebie, a działają w różnych chwilach. Zobacz to w laboratorium:

<KrokPoKroku program="for" />

Zmienna licznika w pętli `for` zwyczajowo nazywa się `i`. Pętla `for` to najczęstszy wybór, gdy wiadomo z góry, ile razy coś powtórzyć.

<Uwaga tytul="Błąd o jeden">
`for (int i = 0; i < 3; i++)` wykona się 3 razy, ale `for (int i = 0; i <= 3; i++)` już 4 razy. Taki „błąd o jeden” to jeden z najczęstszych błędów w programowaniu. Gdy nie masz pewności, rozpisz pętlę w tabelce jak wyżej.
</Uwaga>

## Pętla bez końca

Klocek `forever` też ma swój odpowiednik:

```c
#include <stdbool.h>    // true i false

while (true)            // warunek zawsze spełniony
{
    printf("miau\n");
}
```

Warunek `true` jest zawsze spełniony, więc pętla nigdy się nie kończy. Program przerwiesz w terminalu skrótem **Ctrl+C**. Pętla nieskończona bywa zamierzona (np. gra działa, dopóki jej nie zamkniesz), ale częściej to błąd: zapomniany `licznik++` sprawia, że warunek nigdy nie przestaje być prawdziwy.

## do while: najpierw zrób, potem sprawdź

Czasem trzeba coś zrobić **co najmniej raz**, np. zapytać użytkownika o dane, i powtarzać, dopóki odpowiedź jest zła:

```c title="dodatnia.c"
#include <stdio.h>

int main(void)
{
    // Wartość 0 na start, żeby w n nie było przypadkowych resztek
    int n = 0;
    do
    {
        printf("Podaj liczbę dodatnią: ");
        scanf("%d", &n);    // &n: adres, pod który scanf zapisze liczbę
    }
    while (n < 1);          // pytaj jeszcze raz, dopóki n jest mniejsze od 1

    printf("Dziękuję, %d.\n", n);
}
```

```txt title="Terminal"
Podaj liczbę dodatnią: -2
Podaj liczbę dodatnią: 0
Podaj liczbę dodatnią: 4
Dziękuję, 4.
```

Pętla `do while` sprawdza warunek **po** obrocie, więc pytanie pada zawsze przynajmniej raz. To najprostszy sposób na pilnowanie poprawnych danych. Zwróć uwagę na średnik po `while (n < 1)`: w pętli `do while` jest obowiązkowy.

<Uwaga tytul="Litery zamiast liczby">
Jeśli w tym programie wpiszesz literę, pętla będzie bez końca wypisywać pytanie. `scanf` nie umie zamienić litery na liczbę, więc nie zmienia `n` (zostaje 0), a literę zostawia w kolejce. Przy następnym obrocie trafia na nią znowu. Przerwij program skrótem Ctrl+C. Jak się przed tym zabezpieczyć, pokazuje moduł „printf i scanf” (blok dla dociekliwych).
</Uwaga>

## Którą pętlę wybrać?

| pętla | kiedy | w Scratchu |
|---|---|---|
| `for` | wiadomo, ile razy powtórzyć | `repeat (10)` |
| `while` | powtarzaj, dopóki warunek jest spełniony | `repeat until < >` (z odwrotnym warunkiem) |
| `do while` | zrób co najmniej raz, np. zapytaj o dane | brak |
| `while (true)` | powtarzaj bez końca | `forever` |

Zwróć uwagę na `repeat until`: Scratch powtarza, **aż** warunek będzie spełniony, a C powtarza, **dopóki** jest spełniony. Warunek trzeba więc odwrócić.
