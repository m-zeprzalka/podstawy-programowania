<Ramka tytul="Dla prowadzącego">
Ten moduł opisuje przebieg zajęć na sali. Jeśli uczysz się samodzielnie, możesz go pominąć.
</Ramka>

Pełny materiał tej lekcji to prawie dwie godziny, więc w 90 minutach trzeba ciąć.

## Plan minuta po minucie

| min | treść |
|---|---|
| 0–5 | Moduł 1, ankieta startowa |
| 5–13 | AI, kaczka, zasady korzystania z AI |
| 13–18 | Wejście i wyjście, system jedynkowy |
| 18–30 | System dwójkowy: „31 na ręce”, „żywe żarówki” |
| 30–37 | ASCII: „72 73 33” |
| 37–44 | Unicode i UTF-8: konsola przeglądarki |
| 44–48 | RGB i media (skrót) |
| 48–58 | „Zgadnij liczbę od 1 do 1000” |
| 58–68 | Pseudokod i kanapka |
| 68–86 | Scratch na żywo: „Witaj, świecie”, „Witaj, ty”, „Miau”, warunki |
| 86–90 | Zadanie domowe |

## Co przenieść na lekcję 1

- Oscartime i Ivy’s Hardest Game (ok. 20 min),
- polskie kodowania (8 min),
- przepełnienia i 0.1 + 0.2 (10 min, dobry wstęp do `int` i `float`),
- tokeny (5 min),
- moduł o procesorze i pamięci (5 min).

W wariancie 135-minutowym zostaw je na lekcji 0 i dodaj 15 minut ćwiczeń w parach.
